Odyssey Web Components

Framework-agnostic Custom Elements (<ody-*>) shipped under the @peektravel/app-utilities/ui subpath — the same catalog as docs/ui.md, with every component rendered live below. Light DOM, dependency-free, ported from the Peek Odyssey design system.
