@peektravel/app-utilities TypeScript · npm package

Reference

Interactive reference for the top-level service classes and the clean data models each returns, plus the Odyssey UI web components.

Available Platforms

Peek →
src/models/peek
The Peek backoffice — bookings, products, timeslots, pricing, memberships, reviews, and more, rooted at PeekAccessService.
CNG →
src/models/cng
The CNG backoffice. Rooted at CngAccessService, exposing the CngProductService and the Activity model.
ACME →
src/models/acme
The ACME backoffice. Rooted at AcmeAccessService, exposing the AcmeProductService and the AcmeActivity model.

UI Toolkit

UI Components →
@peektravel/app-utilities/ui
The Odyssey <ody-*> web components — buttons, inputs, tables, dropdowns, datepicker, overlays, and more — each rendered live.

Install

bash 
$ npm install @peektravel/app-utilities

# …or with pnpm / yarn
$ pnpm add @peektravel/app-utilities
$ yarn add @peektravel/app-utilities

Then import what you need — the access services and models from the package root, and the Odyssey web components from the /ui subpath:

app entry · TypeScript
// access service + data models
import { PeekAccessService } from "@peektravel/app-utilities";

// UI web components — registers every <ody-*> element once
import "@peektravel/app-utilities/ui";
import "@peektravel/app-utilities/ui/tokens.css";
import "@peektravel/app-utilities/ui/odyssey.css";
All three siblings share the same auth, retry/backoff, logging, and base error types — callers touch only the access services and the clean data models.
