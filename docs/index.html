@peektravel/app-utilities

Reference

Interactive reference for the top-level service classes and the clean data models each returns. Pick a platform below — every page has a left-nav, live filter, and a light/dark toggle.

Available Platforms

Peek →
src/models/peek
The Peek backoffice. 13 service classes — bookings, products, timeslots, pricing, memberships, reviews, and more — rooted at PeekAccessService.
CNG →
src/models/cng
The CNG backoffice. Rooted at CngAccessService, exposing the CngProductService and the Activity model.
ACME →
src/models/acme
The ACME backoffice. Rooted at AcmeAccessService, exposing the AcmeProductService and the AcmeActivity model.
All three siblings share the same auth, retry/backoff, logging, and base error types — callers touch only the access services and the clean data models.
